# Final Project SQL

## 📌 Project Overview

This project is an **Advanced SQL Database Management System** built using MySQL. It models a university database containing Students, Courses, Instructors, Enrollments, and Departments. The project demonstrates real-world database design along with CRUD operations and advanced SQL queries.

It is designed to strengthen understanding of relational databases and practical SQL query writing.

---

## 🧱 Database Structure

- **Students** → Stores student personal and academic details  
- **Courses** → Stores course information linked with departments  
- **Instructors** → Stores instructor details and department mapping  
- **Enrollments** → Maps students to courses  
- **Departments** → Stores department information  

---

## ⚙️ Key SQL Concepts Used

### 🔹 Basic Operations
- CREATE, INSERT, SELECT, UPDATE, DELETE

### 🔹 Joins
- INNER JOIN  
- LEFT JOIN  
- RIGHT JOIN  
- FULL OUTER JOIN (simulated using UNION)

### 🔹 Subqueries
- Filtering based on aggregated values  
- Nested query logic  

### 🔹 Aggregate Functions
- COUNT(), AVG(), MAX(), MIN()

### 🔹 String Functions
- CONCAT(), UPPER(), LOWER()

### 🔹 Date Functions
- YEAR(), MONTH(), DATEDIFF(), TIMESTAMPDIFF()

### 🔹 Advanced SQL
- CASE statements  
- Window functions (RANK, SUM OVER)  
- GROUP BY with HAVING
